# About
Me chamo Cristian, tenho 32 anos e estou em transição de carreira para desenvolvimento de software, com foco em backend e full-stack.

Iniciei meus estudos com C# e .NET, desenvolvendo APIs RESTful e aplicações desktop com WPF. Venho expandindo conhecimentos em frontend com React (TypeScript/JavaScript) e explorei tanto fintech (PIX, billing, autenticação 2FA) quanto aplicações de negócio (agendamento, CRM).

Com 6 anos em Suporte de Campo (redes, servidores, ERP, POS, bancos de dados) e atuação como Service Desk N2, adquiri experiência prática com SQL Server, Microsoft Azure e infraestrutura crítica. Hoje concentro meus estudos em arquitetura de APIs, banco de dados, DevOps e ambientes Linux.
